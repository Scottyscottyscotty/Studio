## 🎬 Critical Digital Tech Features

### 1. Continuous Listening Mode ✅
**Why it matters:** On a busy set, you can't keep clicking the menu bar.

- **Toggle in menu:** "Continuous Mode: On/Off"
- **Hands-free operation:** Always listening for "Studio" wake word
- **Auto-restart:** Automatically resumes after each command
- **Perfect for:** Tethered shooting, client reviews, rapid culling

**Usage:**
1. Click menu bar icon
2. Enable "Continuous Mode"
3. Keep shooting - just say "Studio" + command anytime

---

### 2. Voice Feedback/Confirmations ✅
**Why it matters:** Know commands worked without looking at screen.

- **Spoken confirmation:** macOS text-to-speech confirms every action
- **Examples:**
  - "Deleted 4 images"
  - "Rated as 5 stars"
  - "Marked as hero shot"
- **Toggle on/off:** "Voice Feedback" menu option
- **Perfect for:** Eyes on the shoot, not the computer

**Voice:**
- Uses macOS Samantha voice
- Fast speech rate (200 wpm)
- Non-intrusive, clear confirmations

---

### 3. Global Keyboard Shortcut ✅
**Why it matters:** Fastest activation without touching menu bar.

- **Hotkey:** `Option + Space`
- **System-wide:** Works even when not focused on Studio
- **Instant:** Activates listening immediately
- **Perfect for:** Quick commands while busy

## 🚀 Usage Patterns for Digital Techs

### During Tethered Shooting

1. **Enable continuous mode** at start of session
2. **Enable voice feedback** for confirmation
3. **Use workflow macros** for rapid culling:
   - "mark as hero" for best shots
   - "mark as selects" for good shots
   - "mark as reject" for outtakes

### Client Review

1. **"Show only flagged"** - Display pre-selected images
2. **"Show only 5 stars"** - Show only hero shots
3. **"Clear filters"** - Return to full gallery
4. **"Show last 20 captures"** - Review recent work

### Batch Processing

1. Select reference image
2. **"Copy adjustments"**
3. Select target images
4. **"Apply settings to flagged"**
5. Done!

### Quality Control

1. **"Show overexposure warning"** - Check highlights
2. Navigate through images
3. **"Hide overexposure"** - Clear overlay

## 💡 Pro Tips

### Efficiency Maximizers

1. **Use continuous mode** - Never click menu again
2. **Learn 5-6 core commands** - Cover 90% of needs:
   - "Mark as hero"
   - "Mark as selects"
   - "Show only flagged"
   - "Clear filters"
   - "Delete last N"
   - "Export selected"

3. **Hotkey muscle memory** - `Option+Space` becomes second nature

4. **Voice feedback off in noisy environments** - Toggle as needed

5. **Combine with keyboard** - Voice for culling, keyboard for editing

### Workflow Combinations

**Rapid Culling:**
```
"Studio, mark as hero"      (best shot)
"Studio, next"
"Studio, mark as selects"   (good shot)
"Studio, next"
"Studio, mark as reject"    (bad shot)
"Studio, next"
```

**Client Presentation:**
```
"Studio, show only 5 stars"
"Studio, start fullscreen"
... present to client ...
"Studio, exit fullscreen"
"Studio, clear filters"
```
